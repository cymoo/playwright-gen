# 基准页面集（按复杂度分档）

用于证明"版本演进随页面复杂度而非刻意分阶段"：每个版本在其对应档应通过；低档版本在高档页面上会力不从心。

| 文件 | 复杂度档位 | 适配版本 | 说明 |
|---|---|---|---|
| `01_static_form.html` | ① 简单/静态 | **v1** | 所有可断言内容初始即在 DOM，单次快照即可写对 |
| `02_visual_icons.html` | ② 视觉相关但静态 | **v1 --vision** | 图标按钮无可见文字，视觉模型更易判断含义 |
| `03_spa_modal.html` | ③ 动态/交互 | **v2** | 弹窗/提示点击后才创建，单次快照看不到，必须驱动浏览器 |
| `04_login_app.html` | ④ 复杂应用 | **v3** | 需登录(admin/secret)后才出现多视图，一句话需拆成套件 |

以 `file://` 直接打开即可（纯 DOM 操作，无需起服务）。例如：

```
file:///Users/neo/playground/playwright-gen/examples/03_spa_modal.html
```
